# Aspire Semantic Search

A minimal sample project demonstrating semantic search using .NET 9, Aspire, Microsoft Semantic Kernel, and in-memory vector storage.

## Overview

This project shows how to:

- Use Microsoft Semantic Kernel for generating text embeddings
- Store and search embeddings using a simple in-memory vector store
- Build distributed .NET applications with Aspire
- Interact with the API using `.http` files (no Swagger UI)


1. Clone the repository:
2. Run The Project
3. Use the api.http file to test endpoints for adding and searching documents.

- No external services (e.g., OpenAI, Azure Cognitive Search) are used
- All embeddings and search operations are handled in memory
